# Planning

Organizer working documents. Not published to the site.

- `design-doc-drafts/` — iterations of the campaign design document before sharing with players
- `dry-run/` — plan and findings from the singleplayer end-to-end converter chain test
- `playbook/` — the converter chain playbook, built during and after the dry run
- `decisions/` — dated decision log; one file per locked decision or related batch

## Decision log format

File name: `YYYY-MM-DD-short-slug.md`.

Each file: what was decided, why, what was explicitly rejected, who signed off. Keep one decision (or one tightly related batch) per file. To change a decision, write a new dated file pointing back at the old one rather than rewriting history — locked decisions stay locked so the timeline remains auditable.
